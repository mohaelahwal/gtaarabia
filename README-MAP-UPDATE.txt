GTA ARABIA — ARABIC INTERACTIVE MAP UPDATE

Install (updated files only)
1. Pull origin in GitHub Desktop before copying these files.
2. Extract this ZIP and copy its contents into the gtaarabia repository root.
   Merge the assets, data, map, scripts and tests folders. Replace matching files.
   Do not delete your existing folders. Do not put the ZIP itself in the repository.
3. Commit the added/updated files, then Push origin.
4. In GitHub Actions, wait for Publish website to finish successfully.
5. Open https://www.gtaarabia.com/map/index.html and refresh with Ctrl+Shift+R.

Included
- 4,854 source locations in 105 populated categories (110 categories in the source).
- Same reference map imagery, colored location symbols and detailed source records.
- GTA Arabia branding, right-to-left Arabic interface and translated categories/common labels.
- Search in Arabic or the original names; grouped filters and category counts.
- Marker photos where supplied, Arabic summaries and structured facts where available.
- Original names and English source descriptions are preserved; detailed English text is
  available inside the collapsed original-source section. This is not a complete Arabic
  translation of every individual source description or proper name.
- Found/not found, hide found, favorites, personal notes and custom markers.
- Saved progress in this browser, JSON export/import, location sharing and fullscreen.
- Nearby pins are grouped into clusters; zoom in to separate them.

Online dependencies
- Overview tiles, app libraries and icons are included locally.
- Detailed zoom levels 4–6 and source photos load from GTABase on demand.
  Their availability depends on that external host. This is not a fully offline map.
- Map data is a snapshot retrieved 24 November 2026. It is not automatically synced.
- Keep the small map attribution and assets/map-kit/CREDITS.txt with the map.
